# 量子隧穿：微观奇迹与跨维度革命

本书是一部**基于真实科学概念的科幻叙事/思想实验作品**。书中结合量子隧穿的真实物理原理与科幻推演，探讨了从微观粒子到星际文明的跨学科图景。

---

## 📖 内容简介

- **真实科学内容**：量子隧穿基础、扫描隧道显微镜（STM）、闪存技术、隧穿场效应晶体管（TFET）、量子生物学（光合作用、酶催化、电子传递链）等。
- **科幻推演**：星际量子通信、量子催化聚变反应堆、月球知识库、全球量子治理机构、量子虫洞模拟、神经接口量子增强等。
- **伦理讨论**：神经接口安全边界、技术普惠与数字鸿沟、量子技术的双重用途，并基于真实国际伦理框架（UNESCO、欧盟）推演未来治理构想。
- **配套代码**：提供基于 Python 的教学演示代码（真实物理公式）和科幻推演代码（仅供思想实验），涵盖隧穿概率计算、STM 电流模拟、TFET 特性、非厄米隧穿、拓扑隧穿、激子传输等。

## 🚀 快速开始

### 1. 查看书籍内容
所有章节的 Markdown 文件位于 `chapters/` 目录，可直接在 GitHub 上浏览，或下载后使用任意 Markdown 阅读器查看。

### 2. 运行代码
代码位于 `code/` 目录，需要 Python 3.10+ 及以下库：

```bash
pip install numpy matplotlib scipy
```

运行代码：
```bash
python code/quantum_tunneling_code.py
```

代码包含：
- **真实物理公式**：矩形势垒隧穿概率、STM 电流、TFET 转移特性、非厄米朗道-齐纳隧穿、拓扑绝缘体表面态隧穿、电子转移速率、激子传输简化模型、WKB 积分。
- **科幻推演函数**：假想的势垒内碰撞、聚变增益、星际通信效率、月球数据寿命、虫洞关联、神经接口风险、合规指数。所有科幻函数均输出警告，仅供思想实验。
